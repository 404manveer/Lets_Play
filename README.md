# Spotify Clone

A full-stack Spotify clone built to learn production-grade engineering practices — React, Next.js, React Native, Node.js, Express, and DevOps (Docker, CI/CD, deployment).

## Structure

spotify-clone/
├── apps/
│   ├── web/       - Next.js frontend
│   ├── api/       - Express backend
│   └── mobile/    - React Native app
├── packages/
│   └── shared-types/  - Shared TypeScript types/DTOs between web and api
